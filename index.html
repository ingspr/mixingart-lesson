HOW IT WORKS

레슨 진행 방식

처음 문의부터 수업 시작까지, 어렵지 않습니다.

01
카카오톡으로 문의
카카오톡 ID mixingart로 문의 주시면 빠르게 답변드립니다. 현재 수강 가능 요일과 일정을 안내해드립니다.
02
과정 선택 및 일정 조율
Core Course 또는 1년 마스터과정 중 목표에 맞는 과정을 선택합니다. 원하는 요일에 선착 자리가 남아 있으면 바로 확정됩니다.
03
1:1 개인 레슨 시작
개인 속도에 맞게 진행하며, 이론과 실전을 병행합니다. 모든 수업은 친절한 소통 중심으로 운영됩니다.
04
Core 수료 → 마스터과정 전환 가능
Core Course 수료 후 1개월 이내 결정 시 기납부 금액을 제외한 나머지만 납부하고 마스터과정으로 바로 진입할 수 있습니다.
